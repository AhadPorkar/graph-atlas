# Sicherheitsrichtlinie

[English](SECURITY.md)

Graph Atlas ist eine Entwicklungsvorschau. Es gibt weder ein veröffentlichtes stabiles
Supportfenster noch eine unabhängige Sicherheitszertifizierung. Für ältere Versionen werden
Fehlerkorrekturen nicht zugesichert.

## Verdächtige Schwachstelle melden

Vertrauliche Sicherheitsmeldungen von GitHub verwenden, **sofern der Repository-Inhaber sie
aktiviert hat**. Andernfalls ohne öffentliche Exploit-Details um einen privaten Kontaktweg bitten.
Diese Vorlage enthält bewusst keine erfundene E-Mail-Adresse.

Betroffenen Commit beziehungsweise Version, Umgebung, Auswirkung und ein minimales bereinigtes
Beispiel nennen. Keine echten Tokens, Passwörter, privaten Pakete, Kundendaten oder einsatzfähigen
öffentlichen Exploits beifügen. Details während der Untersuchung vertraulich behandeln.
Eine feste Reaktionsfrist wird nicht versprochen.

## Vor der Veröffentlichung

Der Inhaber sollte private Meldungen aktivieren, einen echten Kontaktweg einrichten und
Abhängigkeitswarnungen sowie [Betriebssicherheit](docs/de/security.md) prüfen.
CI-Dateien und eine ansprechende README beweisen keine Produktionssicherheit.
