# Product identity

[Deutsch](../de/brand.md) · [Product concept](product.md).

## Working identity

Name: **Graph Atlas**. Descriptor: **Self-hosted artifact and release workspace**. Product sentence: **Artifacts under control. Decisions on record.**

The name is a working identifier, not trademark-cleared. The geometric A mark is an SVG asset in `repository-server/src/main/resources/static/logo.svg`. No competitor logo, copied screenshot, external brand kit or proprietary font is distributed. Existing code-license notices remain intact.

The interface is organized around delivery work: mission control, release lanes, artifact explorer, connection guides and storage intelligence. Registry configuration, containment and maintenance are operational concerns; identities and audit are access concerns. This changes the information hierarchy rather than merely recoloring a repository-management screen.

## Visual language

A warm neutral canvas, a light sage navigation area, dark green hero and lime call-to-action distinguish the application. The principal dark green is `#183f38`; the lime accent is `#d5ef83`. The source CSS is the authority for all tokens. Numbered navigation, restrained status chips, explicit decisions and digest-based records are the reusable elements.

System fonts avoid remote font downloads. SVG and CSS assets are included with the source. English and German use LTR; Persian uses RTL with logical spacing properties. Package names, commands, hashes and technical identifiers retain their original bytes.

## Voice

Use concrete language: “captured,” “reviewed,” “signed,” “held,” “verified at.” Explain whether a result is historical or current. Avoid “unhackable,” “infinite,” “certified,” “AI-powered” or “industry-leading” without evidence. Do not imply a locally signed receipt is a neutral third-party attestation.

Screenshots generated by `tests/ui_test.py` carry a synthetic-workspace marker. Preserve that label in sales material unless the image genuinely represents another clearly described environment.

## Rename safely

For a cleared commercial name, update user-facing README and guides, locale catalogs, HTML metadata and SVG. Search display strings in Java status messages and packaged metadata too. Re-run locale and UI tests after the change.

The API, data keys, `GR_` variables, Java namespace, signature schema and executable filename are compatibility contracts. Do not silently rename them with a global text replacement. Signed existing evidence must remain verifiable. Renaming the product never licenses removing upstream copyright notices.
